Objectif du Projet

Ce projet a pour but de collecter automatiquement des données de livres depuis le site Books to Scrape, en extrayant des informations telles que le titre, le prix, la disponibilité, l’évaluation, la catégorie et l’image. Ces données sont ensuite stockées dans un fichier CSV et les images sont téléchargées localement.

Voici la page du site web a scraper. Pour ce prjet , nous récuperons le titre , le prix , catégorie , disponibilité , évaluation , les images des livres.

💡 Étapes clés du projet

  1. Définition des objectifs Identifier les besoins : quelles données collecter, sur quels sites, à quelle fréquence, et pourquoi ?
  2. Analyse de la structure HTML Étudier le DOM des pages cibles pour repérer les balises contenant les données d'intérêt.
  3. Développement du script Utilisation de Python avec BeautifulSoup, Requests ou Selenium selon les besoins (contenu dynamique, pagination, etc.).
  4. Stockage des données Sauvegarde des résultats dans un fichier CSV ou une base de données relationnelle (MySQL/PostgreSQL).
  5. Analyse & VisualisationExploration des données via Pandas et visualisation avec Matplotlib ou Seaborn.
  6. Automatisation Déploiement du script en tâche planifiée (cron job) pour collecte périodique.

Technologies et Outils Utilisés

  • Python– pour le scraping (Requests, BeautifulSoup, Pandas)
  • HTML & CSS– présentation dans la page web
  • JavaScript – interactivité légère
  • Power BI – visualisation des données exportées

Résultats Obtenus

Le projet a permis de créer un référentiel de plus de 100 livres répartis en catégories avec leurs caractéristiques. Les données exportées en CSV ont été ensuite analysées dans Power BI pour en tirer des statistiques par catégorie, disponibilité, prix moyen, etc. L’interface générée est réutilisable dans d’autres contextes (films, produits e-commerce...)
