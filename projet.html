Project objective

This project aims to automatically collect book data from the “Books to Scrape” website, extracting information such as title, price, availability, rating, category, and image. The data is then stored in a CSV file and images are downloaded locally.

This is the web page to be scraped. For this project, we extract the book title, price, category, availability, rating, and images.

💡 Key Project Steps

  1. Define Objectives Identify needs: what data to collect, from which sites, how often, and why?
  2. Analyze HTML Structure Study the DOM of target pages to locate tags containing relevant data.
  3. Script Development Use Python with BeautifulSoup, Requests, or Selenium depending on needs (dynamic content, pagination, etc.).
  4. Data Storage Save results in a CSV file or a relational database (MySQL/PostgreSQL).
  5. Analysis & Visualization Explore the data using Pandas and visualize insights with Matplotlib or Seaborn.
  6. Automation Deploy the script as a scheduled task (cron job) for periodic collection.

Technologies and Tools Used

  • Python – for scraping (Requests, BeautifulSoup, Pandas)
  • HTML & CSS – for web page layout
  • JavaScript – for light interactivity
  • Power BI – for visualizing the exported data

Results Achieved

The project resulted in a dataset of over 100 books categorized by features. The exported CSV was then analyzed in Power BI to extract statistics by category, availability, average price, etc. The generated interface can be reused in other contexts (movies, e-commerce products, etc.).
