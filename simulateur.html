Project objective

Designing an interactive simulator to calculate monthly mortgage payments

💡 Project Overview

This interactive mortgage loan simulator enables users to instantly compute their monthly payments and total loan cost based on key parameters:

  • Loan Amount
  • Loan Duration (in months/years)
  • Annual Interest Rate

The project combines Power BI with Excel, delivering a modern and responsive user experience across devices.

🛠️ Key Features

  • 🔢 Real-time Calculation – Using standard amortization formula
  • 🎛️ Interactive Controls – Sliders and input fields for parameter tuning
  • 📊 Dynamic Visuals – Display of monthly payment and total cost
  • 🎨 Clean UI Design – High contrast and intuitive layout
  • 💻 Fully Responsive – Works on mobile, tablet and desktop

Results Achieved

  • Simulation time reduced to seconds
  • Clear understanding through intuitive visuals
  • Useful for clients, demo sessions, or website integration

📦 Tools Used

  • ✔️ Microsoft Excel
  • ✔️ Power BI
  • ✔️ Power Query
  • ✔️ DAX (Data Analysis Expressions)
